# exe の作り方（開発機で行う作業）

配布先の端末には Python を入れられないため、**パッケージ済みの exe** を作って
DVD で持ち込む。

---

## 前提

- **開発機**：Windows。Python 3.11 以上（**tkinter を含む**標準インストーラ版）
- **配布先**：Windows・オフライン。exe は実行可（確認済み）
- 持ち込みは DVD

---

## 1. 準備（開発機がインターネットに繋がる場合）

```
python -m pip install -r requirements.txt
```

> `pip` 単体はパスが通っていないことが多いので、`python -m pip` を使う。

## 1'. 準備（開発機もオフラインの場合）

別のネット接続可能な PC で wheel を集めてから持ち込む。

```
python -m pip download -r requirements.txt -d wheels --platform win_amd64 ^
    --python-version 311 --only-binary=:all:
```

開発機で：

```
python -m pip install --no-index --find-links wheels -r requirements.txt
```

## 2. ビルド

```
build\配布物を作る.bat
```

`build\配布物\` に次が揃う。

```
配布物\
  審査データ見直しツール\      ← 2 名 1 組が使う本体
    審査データ見直しツール.exe
    data\                     ← 判定表 CSV。ここを直せば判定が変わる
  書類審査 判断支援ツール\     ← 来年のピークで紙の横に置く
    書類審査 判断支援ツール.exe
    data\
  手引き\
```

個別に作る場合は `build\build_review.bat` / `build\build_tool_b.bat`。

### 書き込みできる場所に置くこと

見直しツールは、exe と同じ場所に次を作る。

```
作業\見直し.db      作業状態（中断と再開のため）
出力\マークアップ\  書き出した画像
data\チェックリスト見本.json   事前バッチの見本
```

読み取り専用の場所に置くと動かない。

---

## なぜ `--onefile` ではなく `--onedir` なのか

1. **起動が速い。** `--onefile` は起動のたびに一時フォルダへ展開するため数秒かかる。
   1 件あたり数十秒で使う道具なので、この差は大きい
2. **セキュリティソフトの誤検知が少ない。** 署名のない `--onefile` の exe は
   検疫されやすい

---

## セキュリティソフトにブロックされたら

署名のない PyInstaller 製 exe は誤検知されることがある。

1. `--onedir` で作り直す（本手順は既にそうしている）
2. 情報システム部門に実行許可を申請する
3. どうしても通らない場合は、判定表 CSV を Excel の関数で引く簡易版に切り替える
   （CSV の形式はそのまま使えるので、作り直しにはならない）

---

## 判定を直すだけなら、ビルドは不要

判定内容は `data` フォルダの CSV にある。**Excel で直して上書きすれば済む。**
ツールB は起動し直すか `F5` で読み直す。

DVD を焼き直す手間があるため、**判定表の修正はピーク前にまとめて行う**こと。
ピーク中に出てきた新しい論点は、ツールが「管理者に相談」で受ける。

---

## 動作確認

ビルド前に、開発機で次を実行して判定エンジンが正しいか確かめる。

```
python tests\test_caselist.py
python tests\test_store.py
python tests\test_rules.py
python tests\test_session.py
python tests\test_markup.py
python tests\test_viewport.py
python tests\test_prescan.py
```

すべて PASS になること。ビルド後は、実機で次を確認する。

- 見直しツールが起動し、判定表の警告が出ないこと
- フォルダを取り込み、作業リストができること
- **OK 案件を 1 件 30 秒以内で流せること**（ここが崩れると全体計画が崩れる）
- 作業窓で左右をまたいで囲むと、線で結ばれること
- 強制終了しても、次の起動で続きから再開できること
