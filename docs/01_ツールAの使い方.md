# 資料作成支援ツール の使い方（作成者向け）

閑散期に、次の 3 つの作業をするためのツール。

1. **カタログ用画像** … PDF からページを選び、マスキングして PNG に書き出す
2. **論点抽出** … チェックリストを見つけ出し、左側を切り出して一覧にする
3. **出力点検** … DVD に焼く前の自主点検

**スキャンデータは端末の外に出しません。** 書き出せるのはマスク済み PNG だけです。

---

## ① カタログ用画像

書類同定カタログに載せる実物画像を作る。必要枚数は合計で数十枚程度。

### 手順

1. **「PDF のフォルダを選ぶ」** で申請書一式のフォルダを指定
   - 「通し番号が奇数のもののみ」にチェックを入れると、申請書一式だけに絞られる
2. 左の一覧から PDF を選ぶ → 右にページのサムネイルが並ぶ
3. **使いたいページをクリックして選ぶ**（青枠が付く）
   - **複数ページを選べる。** 管理票が分割されている場合は、関係するページを全部選ぶ
4. 書き出し先とファイル名の接頭辞を確認して、**「選んだページをマスク編集へ」**

### マスク編集

- **ドラッグで個人情報を囲む。** 囲んだ場所が塗りつぶされる
- 「黒塗り」と「モザイク」を切り替えられる
- 間違えたら **「直前を取り消す」**
- **「このページを書き出す」** で PNG になる。複数ページを選んだ場合は次のページへ進む

**書き出した画像は、元の情報が完全に消えています**（画像に焼き込んでいるため）。
原本の PDF には一切書き込みません。

### 注意

- 申請書一式には**手紙やメモなど、無関係な提出物**が混ざっています。
  予期しない場所に個人情報が出るので、**ページ全体を見てからマスクしてください**
- ファイル名は連番のみです。受給者番号や氏名は入りません

## ② 論点抽出

今年度のチェックリストから、判断がブレた論点を集めるための機能。

### 手順1　見本を登録する

チェックリストのページ位置は PDF ごとに違うため、まず「これがチェックリストです」
という見本を 1 つ登録する。

1. 「見本の PDF を選ぶ」で、チェックリストが入っている PDF を 1 つ選ぶ
2. その PDF の**何ページ目**がチェックリストかを入れる
3. 「見本として登録」

### 手順2　しきい値を決める

1. 「見本 PDF のページ別スコアを見る」を押す
2. ページごとの類似度が出る。**チェックリストのページだけ数字が高い**はず
3. チェックリストとそれ以外の間で、はっきり差が開く値をしきい値にする

例：チェックリストが 0.95、それ以外が最高でも 0.45 なら、しきい値は 0.70 でよい。

**この調整は必ず実データで行ってください。** スキャンの状態によって値が変わります。

### 手順3　まとめて抽出する

1. 対象フォルダと書き出し先を指定
2. 「抽出を実行」

チェックリストの左側（■書類確認欄とメモ欄）が切り出され、
**1 枚に 20 件並んだシート**になって出てきます。

### 使いかた

出てきたシートを見ながら、`templates/論点集計シート.csv` に 1 行ずつ起こす。
NG が付いている場所と、メモ欄の書き込みが論点の手がかりになります。

**全件やる必要はありません。** 300〜400 件も見れば、どの論点が多いかは分かります。

### 切り出し位置がずれるとき

`data/抽出設定.json` で調整できます（無ければ作られます）。

```json
{ "切り出し範囲": { "左側一括": [0.02, 0.10, 0.56, 1.00] } }
```

数字は左・上・右・下の位置を、ページ全体に対する割合で表したもの。
**余白は大きめに取ってください。** スキャンは必ず傾きます。
