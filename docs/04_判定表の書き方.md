# 判定表の書き方（管理者向け）

**このプロジェクトで最も重要な文書。** ツールは決定を配布する手段であって、
決定そのものではない。ここが埋まらなければ、ツールは何も答えられない。

判定表は `data` フォルダの CSV。**Excel でそのまま開いて編集できる**。
編集後、ツールB は起動し直すか F5 キーで読み直す。**exe の作り直しは不要。**

> **文字化けを防ぐため、保存するときは必ず「CSV UTF-8（コンマ区切り）」を選ぶこと。**
> ふつうの「CSV（コンマ区切り）」で保存すると日本語が壊れて読めなくなる。

---

## 大原則

### 迷ったら「相談」にする。空欄にしない

判定表に無い組み合わせは、ツールが自動的に「管理者に相談」を返す。
**無理に OK / NG を決めなくてよい。** 決まっていないものは決まっていないと
書いておく方が、間違った答えを配るより安全。

### 理由を必ず書く

結論だけを配ると、オペレーターは学習しない。毎年同じ質問が繰り返される。
**理由が 1 行あれば、カタログに無い書類にも応用が効く。**

### 「相談」を増やしすぎない

解釈が分かれるものは年 3,000〜4,000 件ある。ここを全部相談で受けると
ピーク期に管理者が破綻する。**頻度が高い論点ほど、決めて OK / NG に倒す。**
相談に残すのは「頻度が低く、影響が大きい」ものに絞る。

## ファイルの役割

| ファイル | 何を決めるか |
|---|---|
| `書類種別.csv` | 画面に出す書類の選択肢 |
| `チェックリスト設問.csv` | 画面に出す設問の一覧（■書類確認のみ） |
| `判定_単独.csv` | **どの書類が有効／無効か**（いちばんよく使う） |
| `判定_組合せ.csv` | 特定の組み合わせだけ例外的に扱いたいとき |
| `判定_突合.csv` | 複数の書類を突き合わせるとき |

---

## 判定_単独.csv の書き方

1 行 ＝ 「この設問で、この書類が出されたらどう扱うか」。

| 列 | 書くこと |
|---|---|
| 設問ID | `チェックリスト設問.csv` にある ID（例 `書3-1`） |
| 書類ID | `書類種別.csv` にある ID（例 `資格確認書`） |
| 区分 | **`有効` / `無効` / `要相談`** のいずれか |
| 理由 | なぜそう扱うのか。オペレーターに表示される |
| 記入方法 | チェックリストのどこに何を書くか |
| 決定状況 | `確定` / `たたき台` / `未決定` など、管理のための覚え書き |
| 決定者・決定日 | 誰がいつ決めたか。**引き継ぎ資産になるので必ず埋める** |

### ツールの判定のしかた

選ばれた書類を見て、次の順で決める。

1. 判定表に無い書類が 1 つでもある → **相談**
2. `要相談` の書類がある → **相談**
3. `有効` が 1 つ以上ある → **OK**
4. すべて `無効` → **NG**

つまり「**有効な書類が 1 点でもあれば OK**」という考え方。
NG の書類が一緒に出ていても、有効なものがあれば OK になる。

### 「提出されていない」も 1 行として書く

書類ID に `未提出` を使う。特別扱いはしていないので、
「未提出は NG」と決めたなら、その 1 行を書く。

---

## 判定_組合せ.csv の書き方

上の「有効が 1 点でもあれば OK」では表せない例外だけを書く。
**単独判定より先に評価される。** 優先度の小さい行から順に見て、最初に当たった行を使う。

| 列 | 書くこと |
|---|---|
| 優先度 | 小さいほど先に評価。10, 20, 30 と間隔を空けておくと後から挟める |
| 必要書類 | この書類が**すべて**出ていること。`|` で区切る |
| 除外書類 | この書類が**1 つも**出ていないこと。`|` で区切る |
| 判定 | `OK` / `NG` / `相談` |

例：`必要書類=マイナポータル医療費`、`除外書類=管理票|領収書`、`判定=NG`
→「マイナポータルの医療費データだけがあり、管理票も領収書も無い」場合に NG。

---

## 判定_突合.csv の書き方

複数の書類を突き合わせる設問で使う。

**パターンを全部書き出す必要はない。** 3 点でも 5 通り、5 点なら 52 通りになって
手に負えなくなる。代わりに「**基準書類に対して、どれが違うか**」だけを書く。

| 列 | 書くこと |
|---|---|
| 設問ID | 例 `書3-2` |
| 比較項目 | 例 `記号番号` `枝番` `氏名` `生年月日` |
| 基準書類 | 正とみなすもの（例 `申請書`） |
| 対象書類 | 基準と比べる相手。`|` 区切り（例 `資格確認書|中サバ照会`） |
| 不一致書類 | **空欄** ＝ 全部一致<br>**`*`** ＝ 1 つ以上が不一致（どれでも）<br>**書類ID** ＝ その書類だけが不一致 |
| 判定 | `OK` / `NG` / `相談` |

### まずはこの 2 行だけ書けばよい

```
比較項目=枝番, 不一致書類=(空欄), 判定=OK      … 全部一致なら OK
比較項目=枝番, 不一致書類=*,       判定=相談    … どれか違えば相談
```

これで「決まっていない」状態を安全に表現できる。
後から「枝番だけ違うのは NG」と決まったら、2 行目の判定を `NG` に変え、
理由を書き直すだけでよい。

より細かく分けたくなったら、`不一致書類` に具体的な書類IDを書いた行を足す。
**具体的に書いた行が、`*` の行より優先される。**

### 複数の比較項目がある場合

項目ごとに判定し、**いちばん強いものを採る**。強さの順は

> **相談 ＞ NG ＞ OK**

「相談」を最優先にしているのは、未解決のものを黙って NG に倒さないため。

---

## 編集したあとに必ずすること

1. ツールB を起動し直す（または F5）
2. **起動時の警告を読む。** 書き間違いがあれば内容を表示する
3. 変えた項目を実際に画面で操作し、意図どおりの結果が出るか確かめる

よくある書き間違い：

- 区分に `有効` `無効` `要相談` 以外を書いた
- `書類種別.csv` に無い書類ID を書いた
- 理由の列を空にした
- 保存形式を「CSV UTF-8」にしなかった（日本語が壊れる）
