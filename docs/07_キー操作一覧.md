# キー操作一覧（印刷して手元に置いてください）

**マウスを使わなくても 1 件が終わります。**
NumLock を切ると、テンキーの 2/4/6/8 が矢印キーになります。
数字・矢印・Enter・`+` `-` `.` `/` がすべてテンキーの上に揃うので、**右手だけで回せます。**

---

## チェックリスト窓

### いつでも使えるキー

| キー | はたらき |
|---|---|
| `Tab` | ①書類選択 ⇄ ②チェックリスト の切り替え（**いま操作している方に青い枠**が出ます） |
| `Space` | **すべて OK**（判定表が決める設問はそのまま） |
| `Enter` | **完了して次へ** |
| `Ctrl+Z` | **元に戻す**（書類の選択・チェック入力のどちらも戻せます） |
| `Ctrl+S` | 保存して閉じる |
| `+` | 次の案件へ |
| `-` | 前の案件へ |
| `.` | 作業窓を開く |
| `/` | 相談へ送る |
| `Esc` | この案件の入力をクリア |

### ① 書類選択ゾーン

| キー | はたらき |
|---|---|
| `1`〜`9`, `0` | 書類を選ぶ／外す（画面の `[1]` `[2]` … が番号です） |

### ② チェックリストゾーン

| キー | はたらき |
|---|---|
| `↑` `↓` | 行を移動（**いまの行に青い枠**が出ます） |
| `1` | ○ OK |
| `2` | × NG |
| `3` | △ 要相談 |
| `4`〜`8` | 不備理由を選ぶ（`4`未提出 `5`不一致 `6`無効書類 `7`書類不足 `8`確認不可） |

## 作業窓

| キー | はたらき |
|---|---|
| `0` / `Esc` | **閲覧**（ドラッグで画像を動かす。**枠は出ません**） |
| `1` | **囲む**（比較箇所をドラッグで囲む） |
| `2` | **隠す**（個人情報をドラッグで囲む） |
| `Tab` | 左右どちらのカラムを操作するか切り替え |
| `←` `→` | ページ送り |
| `+` `-` | 拡大・縮小 |
| `F` | 全体を表示 |
| `B` | このページに印を付ける／外す |
| `Ctrl+Z` | **直前の囲み・マスクを取り消す** |
| `Enter` | この比較を保存 |

> **枠が出るのは「囲む」「隠す」を選んだときだけです。**
> ふいにクリックしても、閲覧中なら何も起きません。

---

## 状態の見分けかた

**色が見分けにくくても分かるよう、記号を付けています。**

| 表示 | 意味 |
|---|---|
| `○ OK` | 不備としない |
| `× NG` | 不備とする |
| `△ 要相談` | 自分で決めない。管理者へ回す |
| `－ 判定不能` | 前提の設問が NG なので、そもそも判断できない |

---

## 配色を変える

メニューの **「配色」** から 8 色を選べます。
**選んだ配色は次に起動したときから変わります。**

| 配色 | 向いている場面 |
|---|---|
| 標準 | 既定 |
| アイボリー | 白がまぶしいと感じるとき |
| ミント / サクラ / スカイ / ラベンダー | 好みで |
| 高コントラスト | 文字を大きく、線を濃くしたいとき |
| ダーク | 暗い部屋、夜間 |

どの配色でも、文字と背景のコントラストが基準（4.5:1）を満たすことを確認しています。

---

## 作業を中断するとき

**入力は打つそばから保存されています。** そのまま閉じて構いません。
停電やアプリの強制終了があっても、編集中の内容は残ります。

次に開くと、**中断した案件から再開**します。
