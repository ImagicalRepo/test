# 導入手順

所要時間はおよそ 15 分です。**何もインストールする必要はありません。**
ブラウザとGoogleアカウントだけで完了します。

---

## その前に：使えるか確認する（2分）

組織の管理設定で Apps Script が止められていることがあります。先に確かめてください。

1. [sheets.new](https://sheets.new) で捨てて構わないスプレッドシートを作る
2. ［拡張機能］→［Apps Script］
3. エディタに次を貼って ▶（実行）

```javascript
function test() { Logger.log('ok'); }
```

| 起きたこと | 判定 |
|---|---|
| 承認画面 → 許可 → 実行ログに `ok` | ✅ 使えます。次へ進んでください |
| 「Googleで確認されていません」の警告 | ✅ 問題ありません。自作スクリプトなので想定どおりです |
| 「管理者によりブロック」等で承認画面が出ない | ❌ このツールは使えません |
| ［拡張機能］に Apps Script が無い | ❌ 同上 |

❌ だった場合は、管理者への依頼か、単体HTML版への切り替えになります（`docs/設計メモ.md` の 8 章）。

---

## 手順1：スプレッドシートを用意する（1分）

1. [sheets.new](https://sheets.new) で新しいスプレッドシートを作る
2. 名前を付ける（例：`業務スケジュール`）
3. **［ファイル］→［設定］→ タイムゾーンが「(GMT+09:00) 東京」になっているか確認する**

> タイムゾーンがずれていると「今日」の判定が1日ずれます。ここだけは必ず確認してください。

---

## 手順2：コードを貼り付ける（8分）

［拡張機能］→［Apps Script］を開きます。貼り付けるのは次の**5ファイルだけ**です。

| # | 貼り付け元（GitHub の `dist/` フォルダ） | 貼り付け先 |
|---|---|---|
| 1 | `dist/コード.gs` | 最初からある `コード.gs` に**全文上書き** |
| 2 | `dist/gantt.html` | 新規HTMLファイル `gantt` |
| 3 | `dist/editor.html` | 新規HTMLファイル `editor` |
| 4 | `dist/json.html` | 新規HTMLファイル `json` |
| 5 | `dist/appsscript.json` | マニフェスト（下記） |

### HTMLファイルの作り方

左の［ファイル］の **＋** →［HTML］→ 名前に `gantt` と入力（`.html` は自動で付きます）。
中身は最初から入っている内容を**全部消してから**貼り付けてください。

`editor`、`json` も同じ手順です。**名前は必ずこの通りに**してください。コードから名前で呼んでいます。

### マニフェスト（appsscript.json）の出し方

1. 左の ⚙️［プロジェクトの設定］
2. 「**appsscript.json マニフェスト ファイルをエディタで表示する**」に **チェック**
3. ［エディタ］に戻ると `appsscript.json` が現れるので、中身を全文置き換える

### 保存

💾（Ctrl+S / ⌘S）で保存します。

---

## 手順3：初期セットアップを実行する（3分）

1. スプレッドシートのタブに戻り、**ページを再読み込み**する
2. メニューに **📅 業務スケジュール** が現れる（出ないときは数秒待ってもう一度再読み込み）
3. ［📅 業務スケジュール］→［**初期セットアップ**］→［OK］

ここで承認を求められます。初回だけです。

```
承認が必要です
  → 権限を確認
  → 自分のアカウントを選ぶ
  → 「このアプリは Google で確認されていません」
      → 詳細
      → (プロジェクト名) に移動（安全ではないページ）
  → 内容を確認して「許可」
```

> この警告は、**自分で書いたスクリプトを自分で動かすとき**に必ず出るものです。
> 外部の誰かが作ったアプリを許可しているわけではありません。

承認後、もう一度［初期セットアップ］を実行してください。完了すると次が自動で行われます。

- 7枚のシート（設定・業務マスタ・工程テンプレート・基準日・工程表・休日マスタ・実行ログ）の作成
- サンプルの業務3件と工程テンプレートの投入
- 内閣府の祝日CSVの取り込み
- 工程表の生成
- 毎日の自動実行トリガーの登録

---

## 手順4：Chat通知をつなぐ（3分）

通知が不要ならこの手順は飛ばして構いません。

1. 通知したい Google Chat のスペースを開く
2. スペース名をクリック →［**アプリと連携**］→［**Webhook を追加**］
3. 名前を付けて作成（例：業務スケジュール）
4. 表示された URL をコピー
5. スプレッドシートの［**設定**］シート → `ChatWebhookURL` の「値」に貼り付け
6. ［📅 業務スケジュール］→［**Chatにテスト通知**］

スペースに投稿されれば完了です。

---

## 手順5：自分の業務に置き換える

サンプルはあくまで例です。ここからが本番の作業になります。

**サンプルを全部消して一から作る場合**は、
［📅 業務スケジュール］→［**サンプルを削除して最初から作る**］を実行してください。
業務マスタ・工程テンプレート・基準日・工程表が空になり（設定と休日マスタは残ります）、
続けて編集画面が開きます。［＋ 業務を追加］から登録してください。

**サンプルを書き換えて使う場合**は次の手順です。

1. ［📅 業務スケジュール］→［**工程テンプレートを編集**］
2. 業務名・基準日の呼び方・周期を、実際のものに書き換える
3. 工程を実際の流れに直す。右側に**実日付が即座に出る**ので、そこで確かめながら進める
4. ［**保存して工程表を作り直す**］
5. ［**スケジュール画面を開く**］で全体を確認

**特に見直してほしいところ**

| 項目 | 理由 |
|---|---|
| 「決裁完了（見込）」の日数 | 起案から何営業日で返ってくるかは団体ごとに違います。仮に3営業日と置いてあります |
| 受付締切から審査会までの日数 | 20営業日前は一例です |
| 団体独自の閉庁日 | ［休日マスタ］シートに直接追加してください（種別は `閉庁`） |
| 振替出勤日 | 同じく休日マスタに、種別 `振替出勤` で追加します |

## 動き出したあと

| いつ | 何が起きるか |
|---|---|
| 毎日 1:00 | 祝日の取り込み、基準日の展開、工程表の再生成 |
| 毎日 8:00（変更可） | Google Chat に「期限超過／本日／まもなく」を投稿 |

通知時刻を変えるときは、［設定］シートの `通知時刻` を直してから
［📅 業務スケジュール］→［通知トリガーを再設定］を実行してください。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| メニューが出ない | スプレッドシートを再読み込み。それでも出ないなら保存できているか確認 |
| 「シートがありません」と出る | ［初期セットアップ］が未実行です |
| 画面が開かない・白いまま | HTMLファイルの名前を確認（`gantt` `editor` `json`、拡張子なしで入力） |
| 通知が来ない | ［設定］シートの `ChatWebhookURL`、［実行ログ］シートのエラー内容を確認 |
| 祝日が入らない | ネットワーク制限の可能性。［休日マスタ］に手入力しても動きます |
| 日付が1日ずれる | スプレッドシートのタイムゾーンを確認（手順1） |
| 画面の下が見切れる | ［設定］シートの `画面の高さ` を下げる（例：640）。または別ウィンドウで開く |
| 回次が `Sat Aug 01 2026...` と表示される | 古い版の不具合です。最新の `コード.gs` に更新し［工程表を再生成］を実行してください |
| 工程表が空 | ［基準日］シートに行があるか確認。基準日ルールが `手動` の業務は手入力が必要です |
| ウェブアプリの `/exec` の URL が開けない | デプロイが古いバージョンを指しています。［デプロイを管理］→ 鉛筆 → バージョンを「新しいバージョン」→［デプロイ］。または［デプロイをテスト］の `/dev` の URL をメニュー →［WebアプリのURLを登録］に貼り付け |
| 画面が「読み込み中…」から進まない | ［📅 業務スケジュール］→［**動作診断**］を実行してください。どこで止まっているかが出ます |

エラーの詳細は［**実行ログ**］シートに残ります。

### 動作診断

［📅 業務スケジュール］→［**動作診断**］で、各シートの行数・データ量・処理時間・
トリガーの登録状況をまとめて確認できます。うまく動かないときは、まずこれを実行してください。

```
OK スプレッドシート        120ms   業務スケジュール（Asia/Tokyo）
OK シート: 工程表          310ms   184 行
OK 営業日カレンダー         90ms   本日 2026-09-09 は営業日
OK 画面データの取得        1450ms  業務 3 / レーン 21 / 通知 6 件
OK データ量                 60ms   142 KB / 工程 184 件
OK トリガー                 40ms   nightlyRefresh, dailyReminder
```

## 引き継ぐとき

定時トリガーは**設置した人のアカウント**で動きます。異動などで引き継ぐ場合は、
**後任の方が**［📅 業務スケジュール］→［通知トリガーを再設定］を実行してください。
これをしないと通知が止まります。
