# はじめての起動（Windows）

**まず「動くかどうか」だけを確かめます。** exe を作るのはその後です。

---

## 必要なもの

**Python を入れられる PC が 1 台。**

審査データのあるオフライン端末には Python を入れられないので、別の PC が要ります。
これは exe を作るためにも必須です（exe のビルドには Python が要ります）。

インターネットに繋がっていると楽ですが、繋がっていなくても構いません（後述）。

---

## 手順1　Python を入れる

<https://www.python.org/downloads/windows/> から **3.11 以上**をダウンロードします。

インストーラで **「Add python.exe to PATH」に必ずチェック**を入れてください。
ここを忘れると、次の手順でコマンドが見つかりません。

画面に必要な tkinter は、標準のインストーラに最初から含まれています。追加作業は不要です。

入ったか確認します。コマンドプロンプトを開いて：

```
python --version
```

`Python 3.11.x` のように出れば成功です。

---

## 手順2　ファイルを持ってくる

GitHub の `claude/rare-disease-cert-review-wl8n70` ブランチから、
ZIP をダウンロードして展開するか、`git clone` します。

展開したフォルダに移動します（フォルダのアドレスバーに `cmd` と打つと、そこで開けます）。

---

## 手順3　必要な部品を入れる

### インターネットに繋がる PC の場合

```
pip install -r requirements.txt
```

### 繋がらない PC の場合

別のネットに繋がる PC で部品を集めてから持ち込みます。

```
pip download -r requirements.txt -d wheels --platform win_amd64 --python-version 311 --only-binary=:all:
```

`wheels` フォルダごと持ち込んで、目的の PC で：

```
pip install --no-index --find-links wheels -r requirements.txt
```

---

## 手順4　見本データを作る

**実データは持ち出せないので、動作確認用の見本を作ります。**

```
python 見本データを作る.py
```

`見本データ` フォルダに、申請書一式に見立てた PDF が 7 件できます。
実物の構成に合わせてあり、次のパターンが入っています。

| 受給者番号 | 内容 |
|---|---|
| 1000001 | 素直な案件（資格確認書と管理票がそろっている） |
| 1000002 | **枝番だけ違う**（毎年ブレている論点。作業窓で見比べる練習用） |
| 1000003 | **保険証と高齢受給者証しか出ていない**（無効書類のパターン） |
| 1000004 | 後から追加書類が届いた案件（同じ受給者番号・別の日付） |

ほかに、臨床調査個人票（通し番号が偶数）と、
ファイル名の規則に合わないファイルも 1 件ずつ入れてあります。
**これらが作業リストに出てこないこと**も確認できます。

---

## 手順5　起動する

```
python tool_review.py
```

## 確認すること

**画面が出れば、まず成功です。** そのうえで次を試してください。

- [ ] 「フォルダを取り込む」で `見本データ` を選ぶ
      → **作業リストに 4 件**（1000001〜1000004）が並ぶ。
      規則外のファイルが 1 件あった旨も表示される
- [ ] 1 件目を選ぶ → チェックリストが **12 問**出る
- [ ] 「資格確認書」にチェック → 書3-1 が自動で **OK** になる
- [ ] 「高齢受給者証」だけにチェック → 書3-1 が **NG（無効書類）**、
      書3-2 と書3-3 が灰色の **「判定不能」**になって入力できなくなる
- [ ] 「すべて OK」を押す → 残りの設問が OK になる
      （判定表が決める設問はそのまま）
- [ ] 「作業窓を開く」→ **左右にページが出る**。それぞれ別々にページを送れる
- [ ] 2 件目（1000002）で、左を申請書・右を資格確認書にして、
      **枝番のところを左右それぞれドラッグで囲む** → **線で結ばれる**
- [ ] 「この比較を保存」→ `出力\マークアップ\` に画像ができる
- [ ] ツール → 出力点検 が開く

## うまくいかないとき

**`python` は認識されていません と出る**
→ 手順1 の「Add python.exe to PATH」を忘れています。Python を入れ直してください。

**`ModuleNotFoundError: No module named 'pymupdf'`（または `PIL`）**
→ 手順3 をやっていません。

**`ModuleNotFoundError: No module named 'tkinter'`**
→ Python を Microsoft Store 版などで入れた可能性があります。
　 python.org の標準インストーラで入れ直してください。

**画面は出るが、判定表の警告が出る**
→ `data` フォルダの CSV に問題があります。内容をそのまま知らせてください。

**それ以外のエラー**
→ **コマンドプロンプトに出た文字をそのまま全部**知らせてください。
　 最後の数行だけでなく、`Traceback` から下を全部お願いします。
