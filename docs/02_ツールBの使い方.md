# 書類審査 判断支援ツール の使い方（オペレーター向け）

**迷ったときだけ使う道具です。** 全部の申請で使う必要はありません。

審査の記録はこれまでどおり**チェックリストに書きます**。
このツールは「どう判断するか」と「どこに何を書くか」を教えるだけです。

---

## 画面の見かた

```
┌─────────────┬──────────────────────────────────┐
│ ① 確認する項目 │ ② 提出された書類を選ぶ                  │
│               │   □ 資格確認書   □ 高齢受給者証 …        │
│ 書1-1 …       │                                        │
│ 書3-1 …  ←    │ ─────────────────────────────────── │
│ 書3-2 …       │ ③ 判定結果                             │
│               │   ┌──────────────────────────┐        │
│               │   │  NG（不備とする）          │        │
│               │   └──────────────────────────┘        │
│               │   理由：…                              │
│               │   チェックリストへの記入：…            │
└─────────────┴──────────────────────────────────┘
```

## 使い方は 2 ステップだけ

1. **左の一覧から、いま確認している項目を選ぶ**
2. **提出された書類にチェックを入れる**（複数可）

これだけで、下に結果が出ます。**「判定」ボタンはありません。**
チェックを変えるたびに結果がすぐ変わります。

---

## 結果は 3 種類

| 表示 | 色 | どうするか |
|---|---|---|
| **OK（不備としない）** | 緑 | 画面の「チェックリストへの記入」のとおりに書く |
| **NG（不備とする）** | 赤 | 同上。不備欄にも記載する |
| **管理者に相談** | 橙 | **自分で決めない。** 管理者に回す |

**「管理者に相談」が出たら、迷わず管理者に回してください。**
これは、まだ答えが決まっていない項目か、めったに無い組み合わせです。
自分で判断すると、去年と違う結果になってしまいます。

---

## 突合（つきあわせ）の画面

書類どうしを見比べる項目では、表が出ます。

```
（基準：申請書）      資格確認書      中サバ照会
記号番号          ○一致 ○不一致 ○－   ○一致 ○不一致 ○－
枝番              ○一致 ○不一致 ○－   ○一致 ○不一致 ○－
```

- **基準の書類（申請書）と見比べて**、同じなら「一致」、違えば「不一致」
- その書類では確認できない項目は **「－」** のまま
- 「－」と未選択の項目は、判定に含まれません

---

## 覚えておくと速いキー

| キー | はたらき |
|---|---|
| `Esc` | 入力を全部消す（次の申請に移るとき） |
| `F5` | 判定表を読み直す（管理者から更新の連絡があったとき） |

---

## こんなときは

**選びたい書類が一覧に無い**
→ 「管理者に相談」を選んでください。判定表に無い書類です。

**結果が「管理者に相談」ばかり出る**
→ 正常です。まだ決まっていない項目が多いためです。管理者に回してください。

**起動時に警告が出た**
→ 判定表に問題があります。**自分で直さず、管理者に連絡してください。**

**ツールが起動しない**
→ 管理者に連絡してください。ツールが無くても審査はできます。
   紙の早見表を使ってください。
