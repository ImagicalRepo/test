# DVD 作成前チェックリスト

**DVD は焼いたら消せません。焼く前が最後の砦です。**

このプロジェクトで情報漏えいが起こりうるのは、ここ 1 箇所だけです。
面倒でも、毎回すべて確認してください。

---

## 1. 機械でできる点検

- [ ] 見直しツールの **ツール → 出力点検**で、書き出しフォルダを点検した
- [ ] 「問題は見つかりませんでした」と表示された

- [ ] **マスキング「未」が 0 件**である（1 件でもあれば持ち出せません）

このチェックが見ているのは次の 3 つだけです。

- ファイル名に個人情報らしき文字が入っていないか
- PNG 以外のファイルが混ざっていないか
- マスクが 1 つも指定されていない画像がないか

> **塗り残しは機械では検出できません。** 次の目視確認が本番です。

---

## 2. 目視での確認（いちばん重要）

- [ ] **書き出した PNG を 1 枚残らず開いて見た**
- [ ] 氏名が残っていない
- [ ] 受給者番号が残っていない
- [ ] 住所が残っていない
- [ ] 生年月日が残っていない
- [ ] 保険の記号番号が残っていない
- [ ] 医療機関名・医師名が残っていない（載せる必要がある場合を除く）
- [ ] **ページの端や裏写りに情報が残っていない**
- [ ] 手紙・メモなど、無関係な提出物が紛れ込んでいない

---

## 3. 形式の確認

- [ ] すべて **PNG** である（PDF や Word が混ざっていない）
- [ ] 画像を別のソフトで開き、**文字を選択・コピーできない**ことを確かめた
      → コピーできる場合、それは画像ではありません。**焼いてはいけません**
- [ ] ファイル名が連番のみである（`img_0001.png` のような形）
- [ ] `_マスク控え.jsonl` を**含めていない**（これは作業用の控えです。持ち出しません）

---

## 4. 持ち出しの確認

- [ ] 持ち出すのは**書き出し専用フォルダの中身だけ**である
- [ ] 原本のスキャンデータを含めていない
- [ ] 承認の範囲内である（マスキング済み画像の持ち出し・印刷は承認済み）

---

## 5. 焼いたあと

- [ ] DVD の中身を**別の PC で開いて**、想定どおりのものだけが入っているか確認した
- [ ] DVD に内容と作成日を記載した
- [ ] 保管場所を決めた

---

## 万一、焼いたあとに個人情報の残存に気づいたら

1. **その DVD の配布を直ちに止める**
2. 配布済みのものをすべて回収する
3. 管理者に報告する
4. 回収した DVD は復元できない方法で廃棄する

**隠さないこと。** 早く報告するほど被害は小さくなります。
