# 周知掲示板システム（単一HTMLファイル版）

管理者が投稿を作成し、閲覧者に共有できるシンプルな掲示板システムです。

## 特徴

- ✅ **完全サーバー不要**（HTMLファイルのみで動作）
- ✅ **ローカルストレージ不使用**（データはHTML内に埋め込み）
- ✅ **ファイル1つで完結**（board.htmlだけでOK）
- ✅ 管理者用の投稿管理画面（パスワード保護）
- ✅ 閲覧者用の見やすい掲示板表示
- ✅ 優先度による色分け表示（重要/通常/参考）
- ✅ レスポンシブデザイン
- ✅ **CORSエラーなし**（外部ファイル読み込み不要）

## ファイル構成

```
📁 共有フォルダ/
├── board.html     # 掲示板（閲覧＋管理機能）
└── README.md      # このファイル（オプション）
```

**重要**: `board.html` 1つだけあれば動作します！

## セットアップ方法

1. **ファイルの配置**
   - `board.html` をネットワーク共有フォルダに配置
   - または、各PCのデスクトップなど、アクセスしやすい場所に配置

2. **閲覧者の使い方**
   - `board.html` をブラウザで開く
   - 最新のお知らせが自動的に表示されます
   - ページをリロード（F5）すれば常に最新の状態が表示されます

3. **管理者の使い方**
   - `board.html` を開いて「🔐 管理者ログイン」ボタンをクリック
   - パスワードを入力してログイン（デフォルト: `admin123`）
   - 投稿を作成・編集・削除
   - **重要**: 「💾 更新版をダウンロード」をクリック
   - ダウンロードした `board.html` を元のファイルに上書き保存

## 詳しい使い方

### 管理者の投稿手順（重要！）

1. `board.html` を開く
2. 「🔐 管理者ログイン」ボタンをクリック
3. パスワードを入力してログイン（デフォルト: `admin123`）
4. 左側のフォームに投稿内容を入力
   - **タイトル**（必須）
   - **内容**（必須）
   - 投稿者名（デフォルト: 管理者）
   - 優先度（重要/通常/参考）
5. 「💾 保存」ボタンをクリック（まだ閲覧者には反映されません）
6. **重要**: 「💾 更新版をダウンロード」をクリック
7. **重要**: ダウンロードした `board.html` を元のファイルに上書き保存
8. 閲覧者がページをリロードすると、新しい内容が表示されます

### 閲覧者の利用方法

1. `board.html` を開く
2. 投稿が新しい順に表示されます
3. ページをリロード（F5）すれば常に最新の状態を確認できます

### 優先度の使い方

- 🔴 **重要（赤）**: 緊急のお知らせ、必読事項
- 🔵 **通常（青）**: 一般的なお知らせ
- ⚪ **参考（グレー）**: 参考情報、補足事項

## セキュリティ設定

### パスワードの変更方法

1. `board.html` をテキストエディタ（メモ帳など）で開く
2. 以下の行を探す：
   ```javascript
   const ADMIN_PASSWORD = 'admin123';
   ```
3. `'admin123'` を任意のパスワードに変更
4. ファイルを保存

⚠️ **注意**: パスワードはファイル内に平文で保存されます。重要な情報を扱う場合は、ファイルへのアクセス権限で制御してください。

## トラブルシューティング

### Q: ブラウザで開けない / セキュリティ警告が出る

**A**:
- モダンブラウザ（Chrome、Firefox、Edge）を使用してください
- ファイルを直接ダブルクリックで開くか、ブラウザにドラッグ&ドロップしてください
- この方式では**CORSエラーは発生しません**（すべてのデータがHTML内にあるため）

### Q: 管理画面で投稿を保存したのに閲覧者画面に反映されない

**A**: 必ず以下の手順を実行してください
1. 管理画面で「💾 更新版をダウンロード」をクリック
2. ダウンロードした `board.html` を元のファイルに**上書き保存**
3. 閲覧者がページをリロード（F5）する

**重要**: 「💾 保存」ボタンは、編集内容を一時的にメモリに保存するだけです。ファイルをダウンロードして上書き保存しないと、閲覧者には反映されません。

### Q: ダウンロードしたファイルを上書きしたのに反映されない

**A**:
- ブラウザのキャッシュが原因の可能性があります
- 「強制リロード」を試してください
  - Windows: `Ctrl + F5` または `Ctrl + Shift + R`
  - Mac: `Command + Shift + R`

### Q: 複数の管理者で同時に編集できる？

**A**:
- このシステムは同時編集に対応していません
- 複数の管理者が同時に編集すると、後で保存（上書き）した内容で上書きされます
- 運用ルールで編集タイミングを調整してください

### Q: 投稿を間違えて削除してしまった

**A**:
- 定期的にバックアップを取っておくことを推奨します
- バックアップがあれば、そのファイルを開いて、削除前のデータをコピーできます

## 技術仕様

- **動作環境**: モダンWebブラウザ（Chrome、Firefox、Edge、Safari）
- **データ形式**: JavaScript変数（HTML内に埋め込み）
- **エンコーディング**: UTF-8
- **必要な権限**: ファイルの読み書き権限

## データバックアップ

定期的に `board.html` のバックアップを取ることを推奨します。

```bash
# 例: 日付付きでバックアップ
cp board.html board_backup_20260108.html
```

Windowsの場合：
```
右クリック > コピー > 貼り付け
ファイル名を「board_backup_20260108.html」などに変更
```

## カスタマイズ

### デザインの変更

`board.html` をテキストエディタで開き、`<style>` タグ内のCSSを編集することで、色やレイアウトを変更できます。

### データの直接編集（上級者向け）

`board.html` をテキストエディタで開き、以下の部分を探して編集できます：

```javascript
let POSTS_DATA = [
    {
        "id": 1,
        "title": "周知掲示板へようこそ",
        ...
    }
];
```

⚠️ **注意**: JSON形式を正確に保たないと、エラーが発生します。通常は管理画面から編集することを推奨します。

## よくある質問

### Q: index.html、admin.html、data.json との違いは？

**A**:
- 旧方式（3ファイル）は、ブラウザのCORSポリシーにより、ローカルでJSONファイルを読み込めない問題がありました
- 新方式（board.html 1ファイル）は、すべてのデータをHTML内に埋め込むことで、この問題を回避しています
- **board.html だけ使えばOKです**

### Q: ネットワーク共有フォルダに置く必要がある？

**A**:
- 必須ではありません
- 複数人で共有する場合は、ネットワーク共有フォルダが便利です
- 個人で使う場合は、デスクトップなど任意の場所でOKです

### Q: スマートフォンでも見られる？

**A**:
- はい、レスポンシブデザインなので、スマートフォンやタブレットでも表示できます
- ただし、管理者の編集作業はPCで行うことを推奨します

## ライセンス

このシステムは自由に改変・配布できます。

## サポート

問題が発生した場合は、`board.html` をテキストエディタで開いて、ブラウザの開発者ツール（F12）でエラーメッセージを確認してください。
