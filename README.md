# 疑問ノート（iPad用 業務習熟支援アプリ）

新任SVが業務中の疑問をその場で手書き・テキストで残し、業務カテゴリごとに整理し、
LDが回答を書き込んで「未解決 → 確認中 → 解決」で管理するためのノートアプリです。
蓄積した疑問と回答は、そのまま引継ぎ資料・新人向けFAQになります。

アプリのインストールや購入ができないiPadでも使えるよう、**Safariで開くだけで動くWebアプリ**として作っています。
ライブラリ依存なし、`docs/` 以下の静的ファイルだけで動きます。

## 画面構成（iPadOS ヒューマンインターフェイスガイドラインに準拠）

サイドバーとコンテンツの2カラム構成。ページを開くとコンテンツ側がプッシュ遷移するので、
手書きのキャンバスを画面幅いっぱいに使えます。

```
┌ サイドバー ────┬ コンテンツ ───────────────┐
│ ホーム          │ ナビゲーションバー         │
│ すべてのページ  │ 検索 / セグメンテッド       │
│ ピン留め        │                            │
│ ── 業務 ──      │ インセットグループドリスト  │
│ ● 受電対応  3   │  ● 未解決                  │
│ ● エスカレ… 1   │  ● 確認中                  │
│ ── タグ ──      │  ● 解決                    │
│ 転送        2   │                            │
└─────────────────┴────────────────────────────┘
                   ページを開く → プッシュ遷移
```

- **システムカラーとセマンティックカラー**のみを使用（systemBlue / systemRed / systemOrange / systemGreen、label、systemGroupedBackground など）。ダークモードは対応する各ダーク版に自動で切り替わります。
- **SF Pro のテキストスタイル**（Large Title 34 / Headline 17 semibold / Body 17 / Subheadline 15 / Footnote 13 など）。`-apple-system-body` を基準にしているので、iPad の文字サイズ設定（Dynamic Type）に追従します。
- **標準部品**：セグメンテッドコントロール、インセットグループドリスト、ポップオーバー、アラート、フォームシート、ナビゲーションバー。コンパクト幅ではポップオーバーが自動でシートになります。
- **アイコン**は SF Symbols に倣った線画で統一（絵文字は使っていません）。
- **最小タップ領域 44pt**、キーボードフォーカスリング、`prefers-reduced-motion` に対応。

## 置き方（配布方法）

どこかに URL として置く必要があります。候補は3つ。

1. **GitHub Pages**（一番手軽）：リポジトリの **Settings → Pages** を開き、
   Source に **Deploy from a branch**、Branch に **`claude/ipad-note-app-usmbla` / `docs`** を選んで Save。
   数十秒後に公開されます（このリポジトリは **https://imagicalrepo.github.io/test/** で公開中）。
   以後 `docs/` に push するたび、GitHub が自動で再公開します。
2. **社内Webサーバー / 共有ストレージのWeb公開領域**：`docs/` フォルダをそのまま置く。
3. **手元だけで試す**：`docs/` があるPCで `python3 -m http.server 8000` を起動し、同じWi-FiのiPadから `http://<PCのIP>:8000/` を開く。

iPadのSafariでURLを開いたら、共有ボタン → **「ホーム画面に追加」**。以後はアプリのように起動できます。

> 注意：Safariの制約で、Filesアプリから `index.html` を直接開く方法は保存が不安定です。必ずURLで開いてください。

## 共有の運用（現状はファイル交換）

今の版は端末内保存なので、SV↔LDの共有は「書き出し → AirDrop → 取り込み」で行います。

- SV：1日の終わりに「書き出し」でLDへAirDrop
- LD：「取り込み」→ 回答を書く → 「書き出し」でSVへ戻す
- SV：「取り込み」で回答が反映される

これが手間なら、次の段階として共通の保存先（社内サーバーやスプレッドシート）へ自動同期する形に発展させられます。
データ構造は `items` 配列（1件 = id / title / body / answer / cat / status / strokes ...）で、同期層を差し替えるだけで済むように分けてあります。

## ファイル構成

```
docs/                  ← GitHub Pages の公開フォルダ
  index.html           画面とスタイル
  app.js               ロジック（保存・一覧・手書き・共有）
  sw.js                オフライン用キャッシュ
  manifest.webmanifest ホーム画面追加用
  icon.svg             アイコン
  .nojekyll            Jekyll の処理を無効化
```

## 動作確認

Chromium で、初回ガイド → 名前登録 → テンプレートから作成 → 手書き・業務・タグ・チェックリスト・回答 → 解決 → リロード後も残る → 業務別一覧 → 3ペイン / 縦向き / スマホ幅の表示、まで確認済み。
iPad実機（Safari / Apple Pencil）での確認はまだなので、最初に実機で手書きの書き味を試してください。
