# 周知掲示板システム

管理者が投稿を作成し、閲覧者に共有できるシンプルな掲示板システムです。

## 特徴

- ✅ サーバー不要（HTMLファイルのみで動作）
- ✅ ローカルストレージ不使用（JSONファイルでデータ管理）
- ✅ 管理者用の投稿管理画面
- ✅ 閲覧者用の見やすい掲示板表示
- ✅ 優先度による色分け表示（重要/通常/参考）
- ✅ レスポンシブデザイン

## ファイル構成

```
📁 共有フォルダ/
├── index.html     # 閲覧者用の掲示板
├── admin.html     # 管理者用の管理画面
├── data.json      # 投稿データ
└── README.md      # このファイル
```

## セットアップ方法

1. **ファイルの配置**
   - 3つのファイル（index.html、admin.html、data.json）を同じフォルダに配置
   - このフォルダをネットワーク共有フォルダに設定

2. **閲覧者の使い方**
   - `index.html` をブラウザで開く
   - 最新のお知らせが自動的に表示されます
   - 「🔄 更新」ボタンで最新情報を取得

3. **管理者の使い方**
   - `admin.html` をブラウザで開く
   - パスワードを入力してログイン（デフォルト: `admin123`）
   - 投稿を作成・編集・削除
   - 「💾 data.jsonをダウンロード」をクリック
   - ダウンロードしたファイルを元のフォルダに上書き保存

## 詳しい使い方

### 管理者の投稿手順

1. `admin.html` を開いてログイン
2. 左側のフォームに投稿内容を入力
   - タイトル（必須）
   - 内容（必須）
   - 投稿者名（デフォルト: 管理者）
   - 優先度（重要/通常/参考）
3. 「💾 保存」ボタンをクリック
4. 「💾 data.jsonをダウンロード」をクリック
5. **重要**: ダウンロードした `data.json` を共有フォルダに上書き保存
6. 閲覧者に更新を通知

### 閲覧者の利用方法

1. `index.html` を開く
2. 投稿が新しい順に表示されます
3. 「🔄 更新」ボタンで最新情報を取得
4. 自動更新機能（5分ごと）も有効

### 優先度の使い方

- 🔴 **重要（赤）**: 緊急のお知らせ、必読事項
- 🔵 **通常（青）**: 一般的なお知らせ
- ⚪ **参考（グレー）**: 参考情報、補足事項

## セキュリティ設定

### パスワードの変更方法

1. `admin.html` をテキストエディタで開く
2. 以下の行を探す：
   ```javascript
   const ADMIN_PASSWORD = 'admin123';
   ```
3. `'admin123'` を任意のパスワードに変更
4. ファイルを保存

⚠️ **注意**: パスワードはファイル内に平文で保存されます。重要な情報を扱う場合は、適切なアクセス制御を別途設定してください。

## トラブルシューティング

### Q: 閲覧者画面で「データの読み込みに失敗しました」と表示される

**A**: 以下を確認してください
- 3つのファイルが同じフォルダにあるか
- `data.json` が正しいJSON形式か
- ブラウザのセキュリティ設定でローカルファイルの読み込みが許可されているか

### Q: 管理画面で投稿を保存したのに閲覧者画面に反映されない

**A**: 必ず以下の手順を実行してください
1. 管理画面で「data.jsonをダウンロード」をクリック
2. ダウンロードしたファイルを共有フォルダに**上書き保存**
3. 閲覧者画面で「🔄 更新」ボタンをクリック

### Q: ブラウザで開けない / セキュリティ警告が出る

**A**:
- モダンブラウザ（Chrome、Firefox、Edge）を使用してください
- ファイルを直接ダブルクリックで開くか、ブラウザにドラッグ&ドロップしてください
- セキュリティ警告が出る場合は、ローカルファイルとして信頼してください

### Q: 複数の管理者で同時に編集できる？

**A**:
- このシステムは同時編集に対応していません
- 複数の管理者が同時に編集すると、後で保存した内容で上書きされます
- 運用ルールで編集タイミングを調整してください

## 技術仕様

- **動作環境**: モダンWebブラウザ（Chrome、Firefox、Edge、Safari）
- **データ形式**: JSON
- **エンコーディング**: UTF-8
- **必要な権限**: ファイルの読み書き権限

## データバックアップ

定期的に `data.json` のバックアップを取ることを推奨します。

```bash
# 例: 日付付きでバックアップ
cp data.json data_backup_20260108.json
```

## カスタマイズ

### デザインの変更

各HTMLファイルの `<style>` タグ内のCSSを編集することで、色やレイアウトを変更できます。

### 自動更新の間隔変更

`index.html` の以下の行を編集：
```javascript
// 5分ごとに自動更新（ミリ秒単位）
setInterval(loadPosts, 5 * 60 * 1000);
```

## ライセンス

このシステムは自由に改変・配布できます。

## サポート

問題が発生した場合は、各HTMLファイルをテキストエディタで開いて、ブラウザの開発者ツール（F12）でエラーメッセージを確認してください。
