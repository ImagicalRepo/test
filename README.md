# 業務スケジュール管理ツール（指定難病 医療費助成ほか）

「審査会が◯日、その20営業日前が受付締切、決裁は起案からN営業日後、その翌々日が封入封緘、その翌日が発送……」
という**基準日から前後へ多段に伸びるスケジュール**を、Googleスプレッドシート・ガント画面・Google Chat 通知で管理します。
指定難病の月次審査会、一斉更新、小児慢性特定疾病など、**周期の違う複数の業務を並べて見る**ことを想定しています。

## 特徴

- **基準日を1つ直せば、ぶら下がる全工程が自動で計算し直される**（審査会が1週間ずれても手直し不要）
- 工程は「基準日から」だけでなく「**前の工程から**」も定義できる（決裁完了＝起案の3営業日後、など）
- **土日・祝日・年末年始の閉庁日を自動で飛ばす**（祝日は内閣府の公開CSVから取得）
- **3つのビュー**で見られる ── 業務横断ガント／業務別の流れ／月間カレンダー
- **カラーテーマ8種**（パステル系4種を含む）とダーク。動きは控えめなアニメーションで補助
- 毎朝、**Google Chat に「期限超過／本日／まもなく」**を自動投稿
- **個人情報を持たない設計**。工程名と日付だけを扱う

## 個人情報について

このツールは**受給者の氏名・疾病名などを一切保持しません**。「11/12 封入封緘」といった工程と日付だけを管理します。
そのため、個人情報保護条例やクラウド利用の内規に関する説明がしやすくなります。
案件単位の進捗管理が必要になった場合は、必ず所属団体の規程を確認してください。

## 必要な権限

**特別なライセンスや申請は不要**です。Googleアカウント（Workspace / 個人）があればそのまま使えます。
初回実行時に、次のスコープをあなた自身が承認します。

| スコープ | 用途 |
|---|---|
| `spreadsheets` | シートの読み書き |
| `script.external_request` | Google Chat への通知、祝日CSVの取得 |
| `script.scriptapp` | 毎日の自動実行トリガー |
| `script.container.ui` | メニュー・画面の表示 |

**カレンダー権限とGmail送信権限は既定では要求しません。**（カレンダー連携は後述の手順で任意に有効化できます）

### 「このアプリはGoogleで確認されていません」と出たら

自分が所有者の自作スクリプトなので問題ありません。［詳細］→［(プロジェクト名)に移動］で進めます。
外部公開しない限り、OAuthの審査は不要です。

### 動かない場合に疑うところ

1. **組織の管理者設定** — 管理コンソールで Apps Script 自体が無効化されていることがあります。
   まず捨てシートで `Logger.log('test')` を1回実行し、承認画面が出るか確認してください。
2. **ネットワーク** — LGWAN接続系の端末からは Google に接続できません。インターネット接続系で使ってください。
3. **トリガーの実行者** — 定時トリガーは**設置した人のアカウント**で動きます。
   異動・アカウント停止で通知が止まるので、引き継ぐときは後任が［通知トリガーを再設定］を実行してください。

## 導入手順

1. Googleスプレッドシートを新規作成する
2. ［拡張機能］→［Apps Script］を開く
3. `apps-script/` 配下のファイルをすべてコピーする
   - `.gs` ファイル → スクリプトファイルとして同名で作成
   - `gantt.html` / `editor.html` / `json.html` → HTMLファイルとして同名で作成
   - `appsscript.json` → ⚙️［プロジェクトの設定］→「appsscript.json マニフェスト ファイルをエディタで表示する」をONにして貼り付け
   - （`clasp` を使う場合は `clasp push` でまとめて送れます）
4. スプレッドシートを開き直す → メニューに **📅 業務スケジュール** が現れる
5. ［**初期セットアップ**］を実行し、権限を承認する
   - シート作成、サンプルの工程テンプレート投入、祝日取得、トリガー登録がまとめて行われます
6. ［設定］シートの **ChatWebhookURL** を埋める（次項）
7. ［**Chatにテスト通知**］で疎通を確認する

### Google Chat の Webhook URL の作り方

通知したい Chat のスペースを開く → スペース名をクリック → ［アプリと連携］→ ［Webhook を追加］→
名前を付けて作成 → 表示された URL をコピー → ［設定］シートの `ChatWebhookURL` に貼り付け。

## 使い方

### 日々の運用

| やりたいこと | 操作 |
|---|---|
| 全体を見る | メニュー →［スケジュール画面を開く］ |
| 工程を完了にする | 画面上の工程をクリック →［完了］／ 工程表シートの「完」にチェック |
| 審査会の日を変える | 画面上の基準日リンクをクリックして入力（全工程が再計算されます） |
| 工程の内容を変える | メニュー →［工程テンプレートを編集］ |
| 通知を今すぐ試す | メニュー →［Chatにテスト通知］ |

毎日 1時に工程表が自動更新され、設定した時刻（既定8時）に Chat へ投稿されます。

### 3つのビュー

画面上部のタブで切り替えます。左側の「期限超過／本日／まもなく」はどのビューでも出ています。

| ビュー | 見えるもの |
|---|---|
| **ガント** | 全業務を横断した時間軸。回次ごとに1レーンで、工程の丸と基準日の◆が並ぶ。**業務どうしの山場の重なり**が一目で分かる。凡例のチップで業務を絞り込み、小/中/大で日付の幅を変えられる |
| **業務別** | 1つの業務を選んで、回次ごとにカード表示。工程が縦のタイムラインで並び、**進捗バー**と各工程の残営業日が出る。「この業務がどう流れるか」を追うとき用 |
| **月間** | 通常のカレンダー形式。複数業務の工程が**業務色のチップで混ざって**日付に乗る。「今月は何がどう重なるのか」を見るとき用。1日に4件以上あるときは［＋N件］で展開 |

### カラーテーマ

右上の［🎨 テーマ］から8種類。選択はブラウザに保存され、工程テンプレート編集画面にも反映されます。

| テーマ | 系統 |
|---|---|
| ペーパー | 標準（白＋青） |
| さくら / ミント / ラベンダー / サンド | パステル系 |
| オーシャン / スレート | 落ち着いた寒色系 |
| ナイト | ダークモード |

業務マスタの「色」は**色名だけ**を持ち、実際の色はテーマ側で決まります。テーマを変えても業務ごとの色分けは保たれます。

アニメーションは、OS側で「視差効果を減らす」を有効にしている場合は自動的に無効になります。

### 工程の定義のしかた

［工程テンプレートを編集］の画面で、各工程を次の形で定義します。**右側に実日付が即時プレビュー**されます。

| 項目 | 内容 |
|---|---|
| 基準 | 何を起点にするか。**基準日**（審査会など）か、**別の工程** |
| 方向 | 前 / 後 |
| 日数 | ずらす日数 |
| 単位 | 営業日 / 暦日 |
| 休日補正 | 計算結果が休日になったとき、なし / 前営業日 / 翌営業日 |
| 通知 | 何営業日前から通知するか |

> 例）「決裁完了」＝ 基準「認定/不認定 決裁の起案」・方向「後」・日数「3」・単位「営業日」

### 基準日ルールの書き方

業務マスタの「基準日ルール」に書くと、回次が自動で並びます。

| 書き方 | 意味 |
|---|---|
| `毎月第2水` | 毎月第2水曜日 |
| `毎月最終金` | 毎月最終金曜日 |
| `毎月15日` | 毎月15日 |
| `毎月末日` | 毎月の末日 |
| `2ヶ月毎第2水 起点2026-04` | 隔月（2026年4月を起点に位相を合わせる） |
| `毎年9月1日` | 毎年9月1日 |
| `手動` | 自動生成せず、基準日シートに手入力する |

計算結果が休日になったときの寄せ方は「基準日休日補正」で指定します。

### 休日の調整

祝日は自動取得されますが、**団体独自の閉庁日や振替出勤**は［休日マスタ］シートに直接足してください。

| 種別 | 意味 |
|---|---|
| `閉庁` | 休みとして扱う（手入力分は自動同期で消えません） |
| `振替出勤` | 休日だが出勤する日。祝日指定より優先されます |

### 人に渡すとき

メニュー →［テンプレートの受け渡し］→［書き出す（JSON）］でコピーし、
渡した先のシートで［読み込む（JSON）］に貼り付けます。個人情報も進捗も含まれません。

## カレンダー連携を有効にする（任意）

既定ではカレンダー権限を要求しない構成です。使う場合のみ：

1. `appsscript.json` の `oauthScopes` に次を追加
   ```json
   "https://www.googleapis.com/auth/calendar"
   ```
2. ［設定］シートの `カレンダー同期` を `ON` にする（`カレンダーID` は空ならメインカレンダー）
3. 一度メニューから［工程表を再生成］を実行し、権限を承認する

以後、毎晩の自動更新でカレンダーへ終日予定として同期されます。

## 開発

コアロジック（営業日計算・基準日展開・工程算出・通知の振り分け）は
GAS の API に依存しない純粋関数として切り出してあり、Node で検証できます。

```bash
npm test          # コアロジックの検証（49件）
```

2026年の実際の祝日を使って、ゴールデンウィーク・年末年始・9月の3連休をまたぐ計算を検証しています。

画面の見た目は、Apps Script にデプロイしなくてもモックデータで確認できます。

```bash
npm run preview        # tests/preview/out/index.html を書き出す（ブラウザで開く）
npm run preview:shot   # 各ビュー・各テーマを撮影し、JSエラーの有無も報告する（要 playwright）
```

| ファイル | 役割 |
|---|---|
| `00_config.gs` | シート定義・設定の既定値 |
| `01_core_date.gs` | 日付ユーティリティ・営業日計算 |
| `02_core_recurrence.gs` | 基準日ルールの解釈と展開 |
| `03_core_schedule.gs` | 工程テンプレート → 実日程の算出 |
| `04_core_digest.gs` | 通知内容の組み立て |
| `10_sheet_io.gs` | シート入出力 |
| `11_setup.gs` | 初期セットアップ・書式・サンプル |
| `12_holidays.gs` | 祝日・閉庁日の同期 |
| `13_generate.gs` | 基準日展開と工程表生成 |
| `14_calendar.gs` | カレンダー同期（任意） |
| `15_notify.gs` | Google Chat 通知 |
| `16_menu.gs` | メニュー・チェックボックス連動 |
| `17_webapp.gs` | スケジュール画面のデータ供給 |
| `18_template_editor.gs` | 工程編集・テンプレート受け渡し |
| `gantt.html` | スケジュール画面（ガント／業務別／月間・テーマ切替） |
| `editor.html` | 工程テンプレート編集画面 |
| `json.html` | テンプレートの書き出し／読み込み |
| `tests/preview/` | 画面をモックデータで描画・撮影する確認用ハーネス |

## 注意

サンプルとして投入される工程名・日数は**一般的な流れの例**です。
実際の要領・決裁ルール・処理日数に合わせて必ず書き換えてください。
