# 疑問ノート（iPad用 業務習熟支援アプリ）

新任SVが業務中の疑問をその場で手書き・テキストで残し、業務カテゴリごとに整理し、
LDが回答を書き込んで「未解決 → 確認中 → 解決」で管理するためのノートアプリです。
蓄積した疑問と回答は、そのまま引継ぎ資料・新人向けFAQになります。

アプリのインストールや購入ができないiPadでも使えるよう、**Safariで開くだけで動くWebアプリ**として作っています。
ライブラリ依存なし、`app/` 以下の静的ファイルだけで動きます。

## 画面構成（OneNoteの「セクション / ページ」を参考）

```
┌ 業務(セクション) ┬ ページ一覧 / ホーム ┬ ページ(エディタ) ┐
│ 🏠 ホーム         │ 検索・ステータス絞込  │ タイトル            │
│ 📚 すべて         │ 📌 ピン留め           │ ステータス/業務/タグ │
│ 📌 ピン留め       │ 🔴 未解決 (n)         │ ✎ 手書きブロック     │
│ 🏷 タグ           │ 🟡 確認中 (n)         │ Ａ テキストブロック   │
│ ■ 受電対応  3     │ 🟢 解決 (n)           │ ☑ チェックリスト     │
│ ■ エスカレ… 1     │                       │ 📷 写真              │
│ ■ …               │   [＋ 疑問を書く]     │ 💬 回答(LDが書く)    │
└───────────────────┴───────────────────────┴─────────────────────┘
```
iPad横向きは3ペイン、縦向きは2ペイン＋ページ全画面、スマホは1ペイン。

## できること

- **ぱっと手書き**：「＋ 疑問を書く」→「手書きですぐ書く」で白い紙が開く。Apple Pencilの筆圧対応、指でも書ける。
  ペン / 蛍光ペン / 消しゴム / 4色 / 3段階の太さ / 取り消し / 紙をドラッグで伸ばす。「✋」でペンのみ受付（手のひら無視）。
- **1ページに何でも混ぜられる**（OneNote風）：手書き・テキスト・チェックリスト・写真を好きな順に追加、並び替え。
  写真はiPadのカメラで画面や紙の資料を撮ってそのまま貼れる。
- **テキスト欄はApple Pencilでそのまま手書き入力可**（iPadOS標準のスクリブル。文字になるので検索できる）
- **テンプレート**：疑問テンプレ（状況/やったこと/聞きたいこと）、手順・チェックリスト、電話・引継ぎメモ。
- **業務（セクション）**：色付きで自由に追加・改名・並び替え。左に業務ごとの未解決件数。新規ページは「未分類」に入るので、あとで整理すればいい。
- **ステータス**：未解決 / 確認中 / 解決。回答を書き始めると自動で「確認中」。回答を読んだSVが「🟢 解決にする」を押す。
- **タグ / タグの概要**：⭐重要 ☑やること 📌あとで見る 👥みんなにも。「🏷 タグ」でタグごとに横断表示（OneNoteのタグの概要）。
- **ピン留め**：よく見るページを一覧の先頭に。
- **ホーム**：未解決 / 確認中 / 新しい回答 / 解決の件数、届いた回答、やること、最近さわったページ。
- **新しい回答の通知**：LDの回答を取り込むと、ホームと一覧に「新しい回答」バッジが出る。
- **履歴**：作成・ステータス変更・回答記入を誰がいつ、を記録。
- **検索**：タイトル・本文・チェック項目・回答・業務を横断。
- **FAQ印刷**：表示中の一覧の「解決」ページを Q&A 形式でまとめて印刷 / PDF保存（引継ぎ資料に）。
- **共有**：「書き出し」で全ページ、ページ右上「⇪」で1ページだけ、JSONを AirDrop / メール / ファイルAppへ。相手側で「取り込み」するとマージ（同じページは新しい方を採用、回答は消えない）。
- **オフライン動作・ダークモード対応**。データは端末内(IndexedDB)に保存。
- **初回ガイド**：最初の起動で使い方4ステップ → 名前登録。見本ページが1枚入っている（削除してOK）。
- **PCのキーボード**：`n` 新規、`/` 検索、`Esc` 閉じる。

## 置き方（配布方法）

どこかにURLとして置く必要があります。候補は3つ。

1. **GitHub Pages**（一番手軽）：このリポジトリの Settings → Pages で `app/` を公開する。
2. **社内Webサーバー / 共有ストレージのWeb公開領域**：`app/` フォルダをそのまま置く。
3. **手元だけで試す**：`app/` があるPCで `python3 -m http.server 8000` を起動し、同じWi-FiのiPadから `http://<PCのIP>:8000/` を開く。

iPadのSafariでURLを開いたら、共有ボタン → **「ホーム画面に追加」**。以後はアプリのように起動できます。

> 注意：Safariの制約で、Filesアプリから `index.html` を直接開く方法は保存が不安定です。必ずURLで開いてください。

## 共有の運用（現状はファイル交換）

今の版は端末内保存なので、SV↔LDの共有は「書き出し → AirDrop → 取り込み」で行います。

- SV：1日の終わりに「書き出し」でLDへAirDrop
- LD：「取り込み」→ 回答を書く → 「書き出し」でSVへ戻す
- SV：「取り込み」で回答が反映される

これが手間なら、次の段階として共通の保存先（社内サーバーやスプレッドシート）へ自動同期する形に発展させられます。
データ構造は `items` 配列（1件 = id / title / body / answer / cat / status / strokes ...）で、同期層を差し替えるだけで済むように分けてあります。

## 動作確認

Chromium で、初回ガイド → 名前登録 → テンプレートから作成 → 手書き・業務・タグ・チェックリスト・回答 → 解決 → リロード後も残る → 業務別一覧 → 3ペイン / 縦向き / スマホ幅の表示、まで確認済み。
iPad実機（Safari / Apple Pencil）での確認はまだなので、最初に実機で手書きの書き味を試してください。
