# 指定難病 一斉更新 書類審査 支援ツール

指定難病受給者証の一斉更新において、書類審査の判断ブレを減らすためのツールと資料。

- **審査件数**：約 1 万件／シーズン（ピークは 6 月中旬〜7 月 15 日頃）
- **オペレーター**：6 名。繁忙期のみの雇用で**毎回入れ替わる**
- **解釈が分かれるもの**：全体の 3〜4 割（3,000〜4,000 件）← ここを減らすのが目標
- **実行環境**：Windows・完全オフライン・Python 導入不可（exe は実行可）・配布は DVD

## 2 つのツール

### ツールA：資料作成支援ツール（作成者／閑散期）

PDF からページを選び、**マスキングして PNG に書き出す**。
チェックリストを自動で見つけ出し、左側を切り出して**コンタクトシート**にまとめる。

```
python tool_a.py
```

### ツールB：審査判断支援ツール（オペレーター／ピーク期）

提出書類を選ぶだけで、**OK / NG / 管理者に相談** と、その理由、
そして**チェックリストのどこに何を書くか**を表示する。

```
python tool_b.py
```

判定ボタンは無い。選んだ瞬間に結果が出る。1 件数十秒で使えることが設計条件。

## 判定内容は CSV にある（exe に埋め込まない）

```
data/
  書類種別.csv            画面に出す書類の選択肢
  チェックリスト設問.csv   画面に出す設問（■書類確認のみ）
  判定_単独.csv           どの書類が有効／無効か
  判定_組合せ.csv         特定の組み合わせの例外
  判定_突合.csv           複数書類の突合
```

**Excel で直せば判定が変わる。exe の作り直しは不要。**
可読形式で残るので、契約終了後もそのまま引き継げる。

> 保存時は必ず「**CSV UTF-8（コンマ区切り）**」を選ぶこと。

**判定表に無い組み合わせは、必ず「管理者に相談」を返す。**
黙って OK を出すことはしない。

## 現在の状態

判定表には、ヒアリングで確認できた範囲だけを入れてある。
**多くは「たたき台」または「未決定」**で、管理者の決定を待っている状態。

未決定の論点は [`templates/未決定論点リスト.csv`](templates/未決定論点リスト.csv) にある。
最優先は **「記号番号は一致しているが枝番のみ相違する場合の扱い」**（毎年ブレている論点）。

## 構成

```
src/shinsa/
  config.py        定数（判定結果、優先順位、パス）
  pdfio.py         PDF のページ画像化
  masking.py       マスキングと安全な書き出し
  contactsheet.py  コンタクトシート生成
  detect.py        チェックリストのページ検出
  extract.py       論点抽出の処理本体（GUI 非依存）
  rules.py         判定エンジン
  ui.py            GUI 共通部品
  app_a.py         ツールA
  app_b.py         ツールB
```

処理本体は GUI から分離してあるため、画面なしで検証・バッチ実行ができる。
